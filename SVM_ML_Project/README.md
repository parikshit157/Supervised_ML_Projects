# Support Vector Machine (SVM) Project

## About
This project implements Support Vector Machine algorithms for classification and regression tasks using the Iris dataset.

## Algorithms Used
- Support Vector Classifier (SVC)
- Support Vector Regression (SVR)

## Dataset
- Iris Flower Dataset

## Technologies Used
- Python
- Scikit-learn

## Output
- Classification Prediction
- Regression Prediction
- Model Performance
