# Decision Tree Machine Learning Project

## About
This project implements the Decision Tree algorithm for solving machine learning problems. It includes both classification and regression models to make predictions.

## Models Used
- Decision Tree Classifier
- Decision Tree Regressor

## Workflow
1. Load the dataset
2. Perform data preprocessing
3. Split data into training and testing sets
4. Train Decision Tree models
5. Make predictions
6. Evaluate model performance

## Technologies Used
- Python
- Pandas
- seaborn
- Scikit-learn

## Output
- Predictions
- Accuracy Score (Classification)
- Error Metrics (Regression)
